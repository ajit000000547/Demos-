# NEXORA

NEXORA is a mobile-first interactive digital world by Ajeet.

## Features
- Futuristic responsive UI
- Explore World
- Mystery Zone
- Reaction, Memory and Target games
- Smart tools
- Achievements
- LocalStorage progress
- Dark/Light theme
- Animation and sound settings
- PWA install support
- Service worker/offline caching
- No API required

## Deploy
Upload the whole folder to GitHub Pages, Vercel or Netlify. Keep the file structure unchanged.

## Important
For PWA installation and service worker features, serve the project through HTTPS (GitHub Pages/Vercel/Netlify does this automatically).
